MasqueCat Web

Experimental browser client. Paste an mc… token containing a relay URL to send through WebTransport → MasqueCat relay → WireGuard/gVisor. The browser cannot originate arbitrary HTTP/3 CONNECT-UDP, so WebTransport is the browser entry into the same MasqueCat relay peer registry. Legacy tc… DERP/WebSocket remains available for compatibility.
